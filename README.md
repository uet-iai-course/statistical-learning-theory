# Lý thuyết học thống kê

Học liệu của học phần **Lý thuyết học thống kê** (`statistical-learning-theory`), Khoa Công nghệ thông tin, Trường Đại học Công nghệ, ĐHQGHN.

Trang web là tệp tĩnh, không cần bước dựng: mở `index.html`, hoặc chạy máy chủ tại thư mục gốc của kho:

```bash
python3 -m http.server 8765
```

Ghi chú bài giảng là Markdown trong `2627-1/materials/lec-NN/`, được hiển thị bởi `2627-1/material-viewer.html`. Khi mở bằng `file://`, trình đọc dùng bản đóng gói `2627-1/material-local-data.js`.
